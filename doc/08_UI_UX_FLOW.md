Version: 1.0

# 1. 문서 목적

본 문서는 Petit Elle 서비스의 사용자 경험(UX)과 화면 이동 흐름(UI Flow)을 정의한다.

고객이 홈페이지 방문부터 예약 완료까지 자연스럽게 진행할 수 있도록 설계한다.

---

# 2. UX 목표

고객은

3분 이내

예약 신청을 완료할 수 있어야 한다.

---

관리자는

1분 이내

예약 승인 처리가 가능해야 한다.
